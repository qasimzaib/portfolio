# OG Image

This file serves as a placeholder for the Open Graph image used for social media sharing.

In a real implementation, you would create an actual image file (png/jpg/webp) named `og-image.png` with dimensions of 1200x630px.

The OG image should include:

- Your name
- Your title (Software Architect & Full-Stack Developer)
- A professional design consistent with your portfolio branding
- Optimally sized for social media sharing

This image will be used when your portfolio is shared on platforms like Twitter, LinkedIn, and Facebook.

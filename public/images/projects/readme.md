# Project Images

This directory should contain the project images referenced in your portfolio.

Recommended image sizes:

- Aspect ratio: 16:9
- Resolution: 1200x675px or higher
- Format: JPEG or WebP for better compression

Example file names (matching the project names in your resume data):

- ecommerce-saas.jpg
- virtual-event.jpg
- headless-checkout.jpg
- dam-platform.jpg

Remember to optimize your images for web (compressing without losing quality) before adding them to this folder.
